io.display.link

One link, in the app or out of it.

io.display.link shows a link on a page or in a step of an action. It can open another action in the app or a page outside it. It only displays and returns nothing.

Read the docsAll components

The simplest one

The whole action file, and roughly what your team sees when it runs.

What you can set

The settings you will reach for most, each with the line of code that turns it on.

url: 'https://status.example.com'

Out of the app. An address with a scheme, such as https://, opens in a new tab.

url: '/actions/users/change_role?id=2'

Into another action. A path without a scheme stays in the app. It opens that action, here with its id.

text: 'Open the invoice'

Your own words. Set text to say what the link opens. Without it, the link shows the URL.

url: 'mailto:ana@northwind.example'

Email addresses. A mailto: address works too. Like every address with a scheme, it opens in a new tab.

io.display.link(null, { url })

A heading, or none. The label is the heading above the link. Pass null for none.

await io.display.link('Map', { url })

On a page or in a step. Put it on a folder page next to a table. In an action it is a step with Continue, or sits in a group next to inputs.
