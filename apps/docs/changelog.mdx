What changed in each release, grouped by part of AwaitIO. Every package has its own version and its own `CHANGELOG.md` on npm.

<Update label="1.1.0" description="October 22, 2026" tags={["Core", "Components", "Theme", "License"]}>
  ## Core

  `awaitio@1.1.0`

  - Component and theme scripts take ReactDOM from the app instead of bundling their own copy.
  - The [theme](/core/theme) has a new `NativeSelect` block for the browser's own drop-down.

  ## Components

  `@awaitio/*@1.1.0`, every component, with the new `@awaitio/select-single-native@1.1.0`

  - Every package now shares its major and minor version with `awaitio`, so `@awaitio/*@1.1.x` goes with `awaitio@1.1.x`. The last number is each package's own and goes up with any change to it.
  - [`io.select.single`](/io/select-single) is a searchable drop-down. The new `clearable` option shows a × that empties the field again.
  - New [`io.select.singleNative`](/io/select-single-native) keeps the browser's own `<select>`, for short lists.

  ## Theme

  `@awaitio/theme-default@1.1.0`

  - Draws the searchable select and the new `NativeSelect` block.

  ## License

  All packages

  - Users are the most real people who had access at the same time in a calendar month. One person with several accounts is one user; scheduled jobs and AI agents do not count.
  - Every organization except non-profits and educational institutions needs a Company License past 3 users, government included. Teaching AwaitIO in a course is free.
  - An agency's clients are counted one by one, also when the agency hosts their apps. An app that many customers pay to use, such as a SaaS, counts all their users together.
  - Only a service for hosting or managing other people's AwaitIO apps is off limits; hosting the apps you built for your clients is fine.
  - A team that cannot afford the license right now can ask for an exception or individual terms at license@awaitio.com.
  - A new Examples section in the license answers common cases. The [pricing page](https://awaitio.com/pricing) shows it word for word.

  ## Migration guide

  From 1.0.0 to 1.1.0.

  <AccordionGroup>
    <Accordion title="awaitio">
      Nothing to change. Update `awaitio` and every `@awaitio/*` package to `^1.1.0` together, so the theme draws the new select.
    </Accordion>
    <Accordion title="@awaitio/select-single">
      Nothing to change in code: the call and its answer stay the same, only the field is now a searchable drop-down. To keep the browser's own `<select>`, install `@awaitio/select-single-native`, register it and call `io.select.singleNative` instead.
    </Accordion>
    <Accordion title="@awaitio/theme-default">
      With `@awaitio/theme-default`, nothing to change. A theme of your own that does not build on the default one has to add a `NativeSelect` block before you use `io.select.singleNative`.
    </Accordion>
    <Accordion title="License">
      Nothing to change in code. Check your user count against the new counting rule and the examples on the [pricing page](https://awaitio.com/pricing).
    </Accordion>
  </AccordionGroup>
</Update>

<Update label="1.0.0" description="October 21, 2026" tags={["Core", "Components", "License"]}>
  First stable release. AwaitIO runs internal tools in production, and from now on the API follows semver: breaking changes come only in a new major version.

  ## Core

  `awaitio@1.0.0`

  - New [`maxFailedLogins`](/core/users#too-many-failed-attempts) option: how many failed logins per email lock it, or `false` to turn the lock off.
  - The log out button in the header is a plain icon without a border, so it does not stand out next to the user's name.
  - The app name in the header and on the login page is larger.

  ## Components

  `@awaitio/*@1.0.0`, every component

  - No changes in behavior. They move to 1.0.0 together with the core.

  ## License

  All packages

  - Users are counted across a group of companies, and the free limit of 3 users applies to individuals too.
  - A 30-day evaluation with any number of users.
  - $250 a month for 11–50 users with standard support, and an Enterprise agreement above 50 users.
  - Whoever runs an app pays for it. An agency may buy the license for its client.
  - Components and plugins may be sold.
  - A written answer or a license confirmation on request, at license@awaitio.com.
  - The license is governed by Czech law.

  See [License and pricing](/license).

  ## Migration guide

  From 0.1.0 to 1.0.0.

  <AccordionGroup>
    <Accordion title="awaitio">
      Nothing to change. `maxFailedLogins` is optional and defaults to `10`, the same lock 0.1.0 had built in.
    </Accordion>
    <Accordion title="@awaitio/*">
      Nothing to change. Update every `@awaitio/*` package to `^1.0.0` together with `awaitio`.
    </Accordion>
    <Accordion title="License">
      Nothing to change in code. Check the user count of your apps against the new tiers in [License and pricing](/license).
    </Accordion>
  </AccordionGroup>
</Update>

<Update label="0.1.0" description="October 21, 2026" tags={["Core", "Components"]}>
  First public release on npm.

  ## Core

  `awaitio@0.1.0`

  - Actions written as async functions that `await` a person's answer through `io`, served together with the UI by the same Node process.
  - Routing, pages, users with login, environments and themes.
  - `ctx` with the user, params, the action, the run id, redirects and loading states.

  ## Components

  `@awaitio/*@0.1.0`, every component

  - Inputs: text, email, URL, textarea, number, boolean, date and datetime.
  - Selects: single, multiple and table, plus confirm.
  - Displays: table, metadata, link, heading, image, Markdown, object and HTML.
  - `@awaitio/layout-basic` and the default theme `@awaitio/theme-default`.
</Update>
