`io.layout.basic()` frames a page with a title and a description and puts the display components below each other. Provided by the `@awaitio/layout-basic` package.

<Frame>

</Frame>

## Install

```bash
npm install @awaitio/layout-basic
```

## Setup

Register it under `basic`, see [Layout components](/core/layout-components):

```ts app.ts {5}
import { layoutBasic } from '@awaitio/layout-basic';

export const app = new AwaitIO({
  // name, actionsDirectory, theme, secret, users, components…
  layouts: { basic: layoutBasic },
});
```

Under `basic`, it also frames every page that returns just display components, titled with the page's name and description.

## Usage

```ts actions/users/index.ts
export const usersPage = app.definePage({
  description: 'Everyone who works with the back office.',
  handler: async ({ io }) => {
    return io.layout.basic({
      title: 'Users',
      description: 'Everyone who works with the back office.',
      children: [io.display.table('All users', { data: await prisma.user.findMany(), columns: ['name', 'email'] })],
    });
  },
});
```

## Props

| Prop          | Type                | Required | Description                                                                   |
| ------------- | ------------------- | -------- | ----------------------------------------------------------------------------- |
| `title`       | `string`            | Required | The heading of the page.                                                      |
| `description` | `string`            | Optional | One line under the title.                                                     |
| `menuItems`   | `ActionRoute[]`     | Optional | Buttons next to the title that open an action, see [Menu items](#menu-items). |
| `children`    | `io.display.*(…)[]` | Required | The display components, top to bottom.                                        |

## Menu items

`menuItems` puts buttons next to the title, each opening an action. Build them with the action's `route()`, the same link a table's [row menu](/io/display-table#row-menu) or `ctx.redirect` takes; the label is the action's name unless you pass one:

```ts actions/integrators/index.ts
import { upsertIntegratorAction } from './upsertIntegratorAction';

export const integratorsPage = app.definePage({
  handler: async ({ io }) => {
    return io.layout.basic({
      title: 'Integrators',
      menuItems: [upsertIntegratorAction.route({ label: 'Create integrator' })],
      children: [io.display.table('All integrators', { data: await prisma.integrator.findMany(), columns: ['name', 'country'] })],
    });
  },
});
```
