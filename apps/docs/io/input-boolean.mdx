`io.input.boolean()` asks a yes or no question and returns `true` or `false`. Provided by the `@awaitio/input-boolean` package.

<Frame>
  <img src="/images/io-input-boolean.png" alt="The label Send a confirmation email above a checked checkbox with the help text to its right" />
</Frame>

## Install

```bash
npm install @awaitio/input-boolean
```

## Setup

Register it under the key you want in `io`, see [Input components](/core/input-components):

```ts app.ts {5}
import { inputBoolean } from '@awaitio/input-boolean';

export const app = new AwaitIO({
  // name, actionsDirectory, theme, secret, users…
  components: { input: { boolean: inputBoolean } },
});
```

## Usage

```ts
const sendEmail = await io.input.boolean('Send a confirmation email', {
  defaultValue: true,
  helpText: 'The customer gets a copy',
});
```

## Props

| Prop           | Type      | Required | Description                                                                                                 |
| -------------- | --------- | -------- | ----------------------------------------------------------------------------------------------------------- |
| `helpText`     | `string`  | Required | Shown to the right of the checkbox: what checking it means.                                                 |
| `defaultValue` | `boolean` | Optional | Whether the box starts checked. Defaults to `false`.                                                        |
| `disabled`     | `boolean` | Optional | Shows the starting value without letting it change; the handler gets that value whatever the browser sends. |

## Returns

`boolean`: `true` when the box is checked, `false` when it is not.

## Built-in validation

Nothing is checked: an unchecked box gives `false`.

## Custom validation

Chain `.validate()` for a check of your own. It runs on the server after the checks above, gets the value the handler would get and returns a message to show under the field, or nothing when the value is fine; see [Custom validation](/core/input-components#custom-validation).

```ts
await io.input.boolean('I have read the refund policy').validate((isChecked) => {
  return isChecked ? undefined : 'Read the refund policy first.';
});
```
