`io.display.metadata()` shows label and value tiles in a folder's page. It only displays and returns nothing. Provided by the `@awaitio/display-metadata` package.

<Frame>
  <img src="/images/io-display-metadata.png" alt="Three tiles: Users 3, Admins 1 and Activity this month 45 with a description" />
</Frame>

## Install

```bash
npm install @awaitio/display-metadata
```

## Setup

Register it under the key you want in `io`:

```ts app.ts {5}
import { displayMetadata } from '@awaitio/display-metadata';

export const app = new AwaitIO({
  // name, actionsDirectory, theme, secret, users…
  components: { display: { metadata: displayMetadata } },
});
```

## Usage

```ts
io.display.metadata(null, {
  items: [
    { label: 'Users', value: users.length },
    { label: 'Admins', value: admins.length },
    { label: 'Activity this month', value: 45, description: 'Logins, runs and messages' },
  ],
});
```

The label is the heading above the tiles; pass `null` for none.

## Props

| Prop    | Type                                                                                            | Required | Description    |
| ------- | ----------------------------------------------------------------------------------------------- | -------- | -------------- |
| `items` | `{ label: string \| null; value: string \| number \| boolean \| null; description?: string }[]` | Required | One tile each. |

A tile with `label: null` shows only its value.

## How values look

Values are shown the same way as in the built-in tables:

| Value                    | Shows                                            |
| ------------------------ | ------------------------------------------------ |
| `1234.5`                 | 1,234.5                                          |
| `'2026-10-16T09:30:00Z'` | Oct 16, 2026, 9:30 AM, in the viewer's time zone |
| `'2026-10-16'`           | Oct 16, 2026                                     |
| `true`, `false`          | Yes, No                                          |
| `null`, `''`             | —                                                |
| any other text           | the text as it is                                |
