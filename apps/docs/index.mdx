AwaitIO runs internal tools in one Node process. You write each tool as an async function; every `await` on `io` asks a person something in the browser and waits for the answer. The same server serves the UI, so there is nothing else to host.

## What you write

```ts actions/accounts/createAccountAction.ts
import { app } from '../../app';

export const createAccountAction = app.defineAction({
  name: 'Create account',
  description: 'Opens a trial account for a new company and invites its owner.',
  handler: async ({ io }) => {
    const { company, ownerEmail } = await io.group({
      company: io.input.text('Company name'),
      ownerEmail: io.input.text('Owner email', { helpText: 'Gets the invitation' }),
    });

    return { company, ownerEmail, plan: 'Trial' };
  },
});
```

## Bring your codebase

A handler is a plain async function that runs in your own Node process, so everything your app already has works inside it. Bring along:

- **your database**: the Prisma client, the ORM or the queries you already use;
- **your business logic**: the services and rules your product runs on, without copying them;
- **logic shared with your API or GraphQL**: the same functions your resolvers and endpoints call;
- **your internal tools**: scripts, utilities, environment variables and any npm package.

AwaitIO only adds `io` to ask a person and `ctx` to know who it is.

```ts actions/refundOrderAction.ts
import { app } from '../app';
import { prisma } from '../prisma';
import { formatMoney } from '../utils/formatMoney';

export const refundOrderAction = app.defineAction({
  name: 'Refund order',
  handler: async ({ io, ctx }) => {
    const orderId = await io.input.text('Order ID');
    const order = await prisma.order.findUniqueOrThrow({ where: { id: orderId } });
    const reason = await io.input.textarea(`Why refund ${formatMoney(order.total)}?`);

    await prisma.refund.create({ data: { orderId, reason, approvedBy: ctx.user.email } });

    return { refunded: formatMoney(order.total) };
  },
});
```

Nothing has to be wrapped, exported to another service or rewritten: between two `await io` calls it is just your code.
